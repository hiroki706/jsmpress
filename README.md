# Jsmpress

## [サービスURL](jsmpress.hiroki-okubo-tokyo.workers.dev)
## [Service URL](jsmpress.hiroki-okubo-tokyo.workers.dev)

Jsmpress is a partial port of [pympress](https://github.com/Cimbali/pympress). It is designed for PDF slides where the page height is doubled, with the top 50% containing the slide content and the bottom 50% containing speaker notes (a common output format for LaTeX Beamer). It supports both a presenter view and a screen sharing view.

Jsmpressは[pympress](https://github.com/Cimbali/pympress)の部分的なクローンです。PDFスライドのページサイズが垂直方向に2倍になっており、上半分にスライド、下半分にスピーカーノートが配置されている形式（Beamerのスピーカーノート出力など）に対応しています。発表者用表示と画面共有用表示の両方をサポートしています。
